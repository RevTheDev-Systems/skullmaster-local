## What's in it

See `v1.1.0-rc.1.md` for the full highlight list. In brief: reliable startup
with MLX failover, Studio reliability + grounded documents, evidence-bound
knowledge graph, capability router with cached discovery, hardened ingestion,
timezone-aware sessions with persistent turn states, verified backup/restore,
authoritative diagnostics, categorized logs, a security review, and engineering
gates (ruff/mypy/pytest/CI).

## Known limitations

- No OCR (scanned PDFs rejected), no video/slides, closed-world (no web search).
- Multi-document Recall@3 is the first quality tuning candidate.
- Local folder rename is a manual step (`docs/naming.md`); the `.app` is
  location-independent.

## Rollback

Pre-stabilization state: branch `baseline/pre-skullmaster-stabilization`
(`882f7d4`). Data is portable via `data/` or a backup zip; migrations are
additive, so older code reads newer data. See `docs/release-checklist.md`.
