# SkullMaster iQ v1.2.0

Feature release on top of v1.1.0. Adds cross-notebook research, a source
comparison artifact, retrieval tuning, optional OCR, and clearer onboarding.

## What's new

- **Cross-notebook research** — an "All notebooks" chat mode answers across the
  whole library with a diversity-merged retrieval pass and notebook-attributed
  citations. Research answers are transient (not saved to a notebook).
- **Source comparison** — a grounded artifact showing where sources agree,
  differ, or add detail, with every position attributed to a real source.
- **Retrieval tuning** — BM25 weighted above the vector signal lifted the RAG
  benchmark's multi-document recall@3 from 0.944 to 1.0, with no change to
  recall@1/@8, MRR, or generation metrics.
- **Optional OCR** — scanned PDF pages are OCR'd only when a PDF's text layer is
  insufficient and Tesseract is installed; text PDFs are never OCR'd.
- **Onboarding** — the landing page now has working "Create account" and
  "Return to logon" buttons.

## Baselines

- RAG: recall@3/@8 1.0, MRR 1.0, page accuracy 1.0, citation
  correctness/completeness 1.0, unsupported-claim 0.0, refusal 1.0.
- Performance: startup 0.82s, ~50 embeddings/s, 42–58 chunks/s ingest,
  21–44ms retrieval, 171MB peak.

## Notes

- OCR requires `brew install tesseract` + `uv pip install pytesseract pillow`;
  diagnostics reports it as an optional WARN when absent.
- Known limitations unchanged (no video/slides, closed-world). See
  `docs/status.md`.
