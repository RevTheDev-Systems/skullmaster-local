## What's new since v1.2.0

- **OCR fixes** — `pillow`/`pytesseract` are declared as the `ocr` optional
  dependency extra (`uv sync --extra ocr`), and OCR now runs on an empty page in
  a mixed PDF even when other pages hold substantial native text (text pages are
  never re-OCR'd).
- **Library search** — 🔍 Search every notebook at once (semantic + keyword);
  results are grouped by notebook and open the exact passage.
- **Typed knowledge graph** — Mind Graph nodes carry an entity type and each edge
  a relation type (controlled vocabularies), with evidence-bound nodes and edges.
- **Graph explorer** — pan/zoom and click-to-focus on the rendered graph.
- **Cross-notebook graphs** — 🧠 Graph builds one graph across all notebooks,
  with evidence naming the notebook each node/edge came from.

## Baselines

- RAG: recall@3/@8 1.0, MRR 1.0, page accuracy 1.0, citation
  correctness/completeness 1.0, unsupported-claim 0.0, refusal 1.0.
- Performance: startup 0.82s, ~50 embeddings/s, 42–58 chunks/s ingest,
  21–44ms retrieval, 171MB peak.

## Notes

- Cross-notebook graphs and research are transient (not saved to a notebook).
- Known limitations unchanged (no video/slides, closed-world). See
  `docs/status.md`.
