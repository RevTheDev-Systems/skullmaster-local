## What's new since v1.6.0

- **Source-scoped tools** — `count_in_sources` (occurrences across a notebook's
  sources) and `find_in_sources` (matching passages with source/page), available
  only inside a research answer with a bounded `{sources:[…]}` context.
- **Bounded multi-step tool budget** — `TOOL_MAX_ROUNDS` (1–5, default 2) drives
  a logged tool loop; repeated calls are short-circuited and the loop always ends
  in a grounded, cited answer.
- Tool catalog now reports each tool's `scope` (`local` / `sources`).
