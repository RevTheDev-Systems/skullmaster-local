## What's new since v1.4.0

- **Local tools (Phase 22)** — a safe, auditable registry (`calculator`,
  `days_between`, `convert`, `word_count`) with strict argument validation and no
  code execution (`GET /api/tools`, `POST /api/tools/run`).
- **Tools wired into research** — the **🧮 Tools** toggle lets one research
  answer use a single logged local tool before the grounded, cited answer
  (`use_tools` on `/api/research`). Grounding and the primary chat path are
  untouched.
- **Vision groundwork** — `qwen2.5vl:7b` (6.0 GB) is installed and routable for
  the `vision` capability, ready for vision-document understanding.
- **Checkout rename reconciled** — canonical local path is `~/skullmaster-iq`;
  remote and package/module names intentionally unchanged; committed baseline now
  stores a repo-relative corpus path.
