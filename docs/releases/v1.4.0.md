# SkullMaster iQ v1.4.0

Feature release on top of v1.3.0. Adds an expanded capability router, a
retrieval-tuning sweep, and the two separate Studio pipelines: Slides and
narrated Video Overviews.

## What's new since v1.3.0

- **Capability router** — `route_plan(capability, min_context=…)` with a fallback
  policy (active → first capable → explicit miss), exposed read-only at
  `GET /api/models/route`.
- **Retrieval tuning** — a chunk size/overlap sweep (`--sweep`,
  `evals/chunk-sweep.json`) shows retrieval is saturated on the current corpus;
  no chunking change was justified.
- **Slides** — grounded decks (3–15 slides with notes), PNG rendering via
  PyMuPDF, an in-app navigator, and Markdown export.
- **Video Overview** — a narrated MP4 built from the deck: slide images + local
  TTS muxed with ffmpeg (requires `ffmpeg` on PATH).

## Baselines

- RAG: recall@3/@8 1.0, MRR 1.0, page accuracy 1.0, citation
  correctness/completeness 1.0, unsupported-claim 0.0, refusal 1.0.
- Performance: startup 0.82s, ~50 embeddings/s, 42–58 chunks/s ingest,
  21–44ms retrieval, 171MB peak; chunk sweep identical across 9 configs.

## Notes

- Slide decks are grounded (cite-or-refuse); Video Overviews require ffmpeg.
- Known limitations otherwise unchanged; see `docs/status.md`.
