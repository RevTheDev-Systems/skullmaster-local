# SkullMaster iQ v1.6.0

Feature release on top of v1.5.0. Adds vision-document understanding: diagrams,
charts, screenshots, and images (standalone and embedded in PDFs) become
searchable, citable sources.

## What's new since v1.5.0

- **Vision-document understanding** — image sources
  (`.png .jpg .jpeg .webp .gif .bmp .tiff .tif`) and images embedded in PDFs are
  transcribed/described by a vision-capable local model and flow through
  chunking, retrieval, and citations. Opt-in, bounded (≤5 PDF images), and it
  never changes the active chat model (`RoutingProvider.chat_with`).
- **Citations open the image** — a 🖼️ View image button shows the original; images
  are served from `/api/media` with correct content types.
- **Diagnostics** reports vision availability as an optional check.

## Baselines

- RAG: recall@3/@8 1.0, MRR 1.0, page accuracy 1.0, citation
