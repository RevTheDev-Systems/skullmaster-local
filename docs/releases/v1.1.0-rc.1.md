# SkullMaster iQ v1.1.0-rc.1

Release candidate. First release after the stabilization program (Phases 0–18),
built on the working v1.0.0 line.

## Highlights

- **Reliable startup** — boot no longer depends on MLX being present; a saved
  MLX model falls back to a reachable Ollama model and keeps the preference.
- **Studio reliability** — malformed model output is retried (never 500s), and
  Excel worksheet titles are sanitized.
- **Grounded documents** — new text artifacts: briefing, study guide, FAQ,
  timeline, source summary (Markdown download), alongside charts, infographics,
  spreadsheets, and audio.
- **Source-grounded knowledge graph** — every Mind Graph node is bound to the
  passage it came from.
- **Capability router** — models carry chat/reasoning/embedding/vision/tools and
  context length; providers report healthy/degraded/offline; metadata cached
  (warm discovery ~35× faster).
- **Hardened ingestion** — real HTML parsing, fail-closed errors, full
  positive/negative fixture matrix.
- **Auth & persistence** — timezone-aware session expiry; chat turns are kept as
  `interrupted` rather than lost.
- **Operations** — backup/restore (verified round trip), authoritative
  diagnostics, categorized logs, security review.

## Verification

- **181 automated tests pass**; ruff, format, and mypy clean; CI configured.
- RAG baseline (`evals/baseline.json`): recall@8 1.0, MRR 1.0, citation
  correctness/completeness 1.0, unsupported-claim rate 0.0, refusal accuracy 1.0.
- Performance baseline (`evals/benchmarks-baseline.json`): startup 0.82s,
  ~50 embeddings/s, 42–58 chunks/s ingest, 21–44ms retrieval, 171MB peak.

## Known limitations

- No OCR (scanned PDFs are rejected); no video/slides; closed-world (no web
  search).
- Multi-document Recall@3 is the first quality tuning candidate (see
  `docs/performance.md`, Phase 5 baseline).
- The macOS `.app` is location-independent but the local folder rename is a
  manual step (`docs/naming.md`).
