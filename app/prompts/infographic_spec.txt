- Every number, name, and claim must come from the source material verbatim or by direct arithmetic on stated values. Never invent facts.

- Keep all text tight: stat values under 12 characters, stat labels under 40, bullet points under 90.

Output ONLY a JSON object, no prose, no markdown fences, in exactly this shape:
{
  "title": "infographic headline (under 60 chars)",
  "subtitle": "one-line framing (under 90 chars)",
  "stats": [
    {"value": "42%", "label": "what this number is"},
    ...2 to 4 entries...
  ],
  "sections": [
    {"heading": "section heading (under 35 chars)", "points": ["point", "point"]},
    ...1 to 3 sections, 2-4 points each...
  ],
  "source_note": "one short sentence naming which source(s) this draws on"
}
